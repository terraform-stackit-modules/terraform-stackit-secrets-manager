# Terraform STACKIT Secrets Manager module

Terraform module which provisions a [STACKIT Secrets Manager](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/secretsmanager_instance) instance and its users on [STACKIT](https://www.stackit.de/en/).

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "secrets_manager" {
  source  = "terraform-stackit-modules/secrets-manager/stackit"
  version = ">= 1.0.0"

  project_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name       = "app-secrets"
  acls       = ["0.0.0.0/0"]

  users = {
    reader = {
      description   = "read-only consumer"
      write_enabled = false
    }
    writer = {
      description   = "read-write app user"
      write_enabled = true
    }
  }
}
```

See [`examples/basic`](./examples/basic) for a self-contained example (requires only `project_id`).

## Composite module

- `modules/instance` — the `stackit_secretsmanager_instance` (toggled by `create_instance`),
  optionally encrypted with a STACKIT-KMS key (`kms_key`).
- `modules/user` — `stackit_secretsmanager_user` entries (`for_each` over `users`).

The root wires them together and, when `create_instance = false`, targets an existing instance via
`instance_id` for user management.

## Notes

- `stackit_secretsmanager_instance` / `_user` are **region-agnostic** — this module has no `region`
  variable (like the DNS module).
- User `username`/`password` are **auto-generated** (not chosen); the password is exposed via the
  **sensitive** `user_passwords` output. `description` and `write_enabled` are required and the
  `description` is immutable after creation.
- `users` is a map keyed by a **stable identifier**; the instance\_id (known after apply when the
  instance is created here) is only a resource attribute, never a `for_each` key.

## Terratest

The `test/` directory holds a Terratest integration test that applies the `examples/basic` root module against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-secrets-manager
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
go test -v -timeout 45m ./...
```
